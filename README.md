# Core de seguros: la póliza de punta a punta

El sistema donde vive cada póliza, contado para cualquier área: el modelo de datos de la póliza, el configurador de productos, los colectivos y masivos, la cotización y la emisión, los endosos, las renovaciones y cancelaciones, la facturación y la cobranza de primas, la integración con canales, contabilidad y reaseguro, y la modernización del core.

**Ver en línea:** https://aaramirez.github.io/core-de-seguros/
